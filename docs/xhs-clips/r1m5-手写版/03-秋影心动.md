# 为了混学分进摄影社,我错了

说实话,我加摄影社纯为了混学分。
结果第一次例会,副社长 Lily 扫了一眼我的相机:

> "I'm impressed with your setup."
(你这套装备不错。)

……然后我就莫名其妙开始认真拍照了。

社团里有 5 个女生,完全不是一个类型:

**Lily**｜副社长兼学生会主席。强势,严格,但认真起来的样子很让人挪不开眼。
**Mia**｜美术系学姐。说话很轻,笑的时候很少——但你发的每一条动态,她都看过。
**Ava**｜篮球队队长。嗓门大到能喊穿整个球场,"Let's go!" 是她的口头禅。
**Sofia**｜校园广播站主播。声音温柔到离谱,每次听到她念片头,我都会停下手里的活。
**Grace**｜数学系学霸。天然呆,眼睛会发光,看你的眼神像在看一道有趣的题。

最要命的是暗房:例会结束后一起洗照片,红光里,她离你只有一步的距离。
那一段是英文写的,我长按看了三遍译文。

CET4 难度,校园场景,口语很地道。我现在的进度是——全都想认识一下。(别骂了)

# 这游戏的学习系统,比游戏本身还狠

玩了几十轮,来认真说说「边玩文游边学英语」的机制。不是广告,是攻略。

🎭 恋爱部分
① 每个选项都是你真实的英语回应:关心、逗趣、还是直接撩——不同态度加的好感度 / 心动值不一样,选完会飘字告诉你加了多少。
② 好感度到阈值会「锁线」:锁线之后,其他角色自动淡出,不再有关键互动。想开后宫?系统不允许。
③ 结局分 HE / BE:好感度不够是真的会走 BE,会难过的那种。
④ 特定场景 + 特定好感,会触发「心动时刻」卡片。

📖 学习部分
① 长按句子 → 译文弹出(点译);长按 / 双击单词 → 释义 + 一键进生词本。
② 生词本按艾宾浩斯曲线安排复习(第 1·2·4·7 天)。
③ 每章结束有章末复盘:本局学到的表达清单,可以收藏。
④ 学习中心有今日一句、学习统计、7 日周报;还能看学习时长的日/周/月排行榜。
⑤ 五档难度直接选(HS / CET4 / CET6 / 考研 / 托福),点选即生效,随时能换——玩哪档卡就配哪档词库。

💡 我的用法:第一遍裸玩不查词,全靠上下文猜;第二遍才长按补漏。
猜出来的词,比查出来的记得牢。

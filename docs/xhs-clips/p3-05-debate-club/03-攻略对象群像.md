# 5 个攻略对象,你先选谁

恋爱和学习是可以一起要的。👥

「从替补到决赛」里有 5 个可攻略对象,每个都有独立人设和立绘:

**Tessa**｜辩论社王牌辩手——逻辑锋利,台下会把你被驳倒的论点一条条拆给你听
**Yuki**｜辩论社记录员——安静细致,赛后会递来写满批注的笔记
**Quinn**｜辩论社社长——强势认真,招新时一眼看中了替补席上的你
**Blaire**｜对手校的王牌辩手——赛场上针锋相对,赛后却在校门口等你出来
**Hana**｜校报记者——相机里存了九张你在台上讲话的照片

玩法不是点点点就完事:选项分"态度"(撩 / 暖心 / 逗趣),好感值够了会**锁线**——锁线之后其他角色自动淡出,只能走你选的那个人,结局分 HE 和 BE(HE 需要好感度 75+ 且触发心动时刻)。

而且每一段对话都是真实口语,不是课文腔:
> "Hi, Ryan! Are you here for the debate club too?"

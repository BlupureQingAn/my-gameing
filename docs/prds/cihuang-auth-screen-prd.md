# 《词谎》站内登录页 PRD

- 日期：2026-10-26
- 状态：已定案，实施完成待发布
- 需求方：小徐

## 1. 背景与目标

《词谎》此前没有自己的登录界面：未登录游客在账号区、购买弹窗、排行榜与设置中看到的都是「去主站登录」链接，点击即离开游戏跳转云吞吞主站。该路径打断牌桌体验，也与小徐「游客不再强制去主站登录」的要求不符。

本次目标是在游戏内提供与世界观一致的全屏账号页，覆盖登录、注册、找回密码三条流程，游客可随时关闭并继续用高中词库试玩。

## 2. 范围

### 2.1 包含

- 游戏内全屏登录页，三态切换：登录、注册、找回密码。
- 账号密码登录，复用主站 PocketBase 用户库。
- 邮箱验证码注册：验证码发送、60 秒冷却、邮箱与密码校验、可选昵称。
- 邮箱验证码重置密码，成功后自动登录。
- 登录成功后的会话写入、完整版权益刷新、云档同步与菜单刷新。
- 已登录账号面板与退出登录。
- 账号区、购买弹窗、排行榜、设置中的全部主站登录跳转替换为站内登录页。

### 2.2 不包含

- 第三方登录（微信 / QQ 等），仍只在主站提供。
- 账号资料编辑、换绑邮箱、修改密码（已登录状态）。
- 游客与登录账号之间的本地档案隔离策略调整，沿用现有合并逻辑。

## 3. 交互与入口

| 入口 | 行为 |
| --- | --- |
| 菜单账号区「登录 / 注册」 | 打开登录页，默认登录标签 |
| 购买弹窗「登录后购买」 | 关闭购买弹窗并打开登录页；登录成功后自动重新打开购买弹窗 |
| 排行榜「登录」 | 关闭排行榜并打开登录页；登录成功后自动重新打开排行榜 |
| 设置「登录 / 注册」 | 关闭设置并打开登录页 |
| 已登录账号昵称 | 打开账号面板，展示昵称、账号、完整版状态、水晶与退出登录 |
| 设置「退出」 | 二次确认后清除本地会话，回到游客状态 |

游客可以直接关闭登录页（右上角 ×、点击页面空白或 Escape），继续免费游玩高中词库。登录页内提供「忘记密码？」与注册/登录互切链接。

## 4. 表单与校验

### 4.1 登录

- 账号：邮箱或用户名，必填，去除首尾空格。
- 密码：必填。
- 提交调用 `POST https://db.blupure.cn/api/collections/users/auth-with-password`。
- 400 统一提示「账号或密码错误」；429 提示尝试次数过多。

### 4.2 注册

- 邮箱：正则校验，统一转小写。
- 验证码：6 位数字，调用同域 `POST /api/auth/send-code`，`purpose=register`，发送后 63 秒倒计时；429 按服务端 `retryAfter` 对齐。
- 昵称：可选，3-30 位字母、数字、下划线或短横线；作为 `username` 与 `nickname` 落库。
- 密码与确认密码：至少 8 位且两次一致。
- 提交调用 `POST /api/auth/register`，成功返回 token 后直接登录。

### 4.3 找回密码

- 邮箱、6 位验证码（`purpose=reset`）、新密码与确认密码，规则同注册。
- 提交调用 `POST /api/auth/reset-password`，成功后自动登录；若服务端未签发 token，切换回登录标签并提示使用新密码登录。

## 5. 会话与状态

- 登录态继续写主站共享的三个键：`pb_auth_token`、`pb_auth_email`、`bitlife_user_cache_v1`，保持主站与游戏互通。
- 登录成功：清除旧的完整版本地缓存，调用 `/api/cihuang/entitlement` 拉取买断状态，刷新账号区、词库锁定状态与菜单统计，并在已解锁时合并云档与生词本。
- 退出登录：删除上述三个键与 `cihuang_license_v1`，重新拉取权益（未登录直接清空），菜单刷新；本机档案与进度保留，云档不删除。
- 未登录状态下不请求 `/api/cihuang/*` 私有接口。

## 6. 视觉

- 全屏暗色覆盖层，背景使用酒馆原画叠加暗色渐变与琥珀色光晕。
- 左侧为账号侧栏：账房标题、词谎标识、权益说明与酒保引语；窄屏（≤820px）压缩为顶部标识条并隐藏权益列表。
- 右侧为表单卡片：三标签切换、错误/成功提示区、输入框、验证码行、主按钮与游客提示。
- 输入框聚焦为琥珀边框，成功提示绿色，错误提示红色；沿用 Fusion Pixel 字体与现有配色变量。

## 7. 技术实现

- 新增 `cihuang/src/platform/auth.js`：登录、发码、注册、重置接口封装与纯表单校验函数，便于单测。
- `cihuang/src/platform/cloud.js`：新增 `accountIdentity`、`storeAuthSession`、`clearAuthSession`。
- `cihuang/src/ui/main.js`：新增全屏登录页、三态渲染、验证码倒计时、提交处理、账号面板与退出流程，替换全部主站登录入口。
- `cihuang/assets/style.css`：登录页与账号按钮样式。
- 新增 `cihuang/tests/auth.test.js` 覆盖校验规则。

## 8. 验收标准

1. 游客点击账号区、购买、排行榜、设置的登录入口均打开游戏内登录页，不再跳转主站。
2. 登录、注册、找回密码三条流程在游戏内闭环；注册与找回可收到并校验验证码。
3. 登录成功后账号区显示昵称，完整版账号解锁五档词库；从购买/排行榜入口登录后可自动回到原流程。
4. 登录页可关闭，游客继续免费游玩；关闭不残留半开状态。
5. 退出登录后回到游客状态，完整版词库重新上锁，本机进度保留。
6. 现有 63 项单测通过，构建产物与版本号同步。

## 9. 发布计划

- 资源版本提升至 `?v=20261026l`（`index.html` 与 `service-worker.js` 同步）。
- 重建 `cihuang/assets/game.js`，本地提交后等待上线授权。
- 发布流程：`git push origin main:main` → 服务器 `/var/www/bitlife` 快进 → 线上冒烟（页面、资源、登录接口连通性）。worker 无改动。

## 10. 风险

- 登录页依赖主站 PocketBase 的 CORS 与 worker 的 `/api/auth/*` 路由，两者已验证可用；PB 域名异常时登录会提示网络错误，游客仍可试玩。
- 验证码邮件到达率受邮箱服务商影响，沿用主站提示文案（换邮箱、查垃圾箱）。
- 未登录时清除完整版缓存是既有语义，退出登录后需重新校验权益，属预期行为。

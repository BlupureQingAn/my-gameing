## 3. 卡数据结构扩展(结构化卡 schema)

在现有 top-level 键(text/structured{band/theme/world/identity/npcs/timeline/scene_style/first_scene})基础上新增:

```jsonc
{
  // ...现有键原样
  "gender_target": "female",              // female=女向(攻略 5 男) | male=男向(攻略 5 女)
  "love_mode": true,                       // 恋爱攻略卡标记(卡库筛选/播放壳识别)
  "structured": {
    "npcs": [ /* 现结构 npcs 就是可攻略池:每角色 5 人,细化: */ ],
    "love_rules": {
      "slots": 3,                          // 最多并行推进线数(超出需抉择)
      "lock_at": 70,                       // affection ≥ 70 触发锁线提示(自动锁)
      "he_end": { "min_affection": 75, "heartbeat_min": 1 },
      "be_end": { "min_affection": 30 },   // 未达 HE 阈值但走完线 → BE
      "affection": {                        // 标签模板(可被产卡/卡配置覆盖)
        "flirt": 6, "kind": 4, "tease": 2, "neutral": 0, "awkward": -2, "rude": -4, "reject": -6
      }
    },
    "scenes": { "heartbeat": [/* 心动时刻触发点定义(地点/条件/角色) */] }
  }
}
```

NPC 精修人设卡(npcs[] 每项,产卡时 AI 按模板细写):
`name / gender / age / avatar 属性 / role(身份:学长/篮球队长/书店店员…) / appearance(外貌:发色身高气质…) / personality(性格,正向) / hobby(兴趣) / redline(雷区) / soft(心动点) / speech(说话习惯:口头禅/语速/称呼习惯)`

**判定准则:5 个可攻略 NPC = structured.npcs 全体(≥5),且 gender 与 gender_target 互补**(女向卡 npcs 全男,男向卡 npcs 全女),QC 时硬校验。

## 4. 引擎改造方案(按实现顺序)

### 4.1 选项好感标签协议与结算
- **AI 输出协议扩展**:选项对象从纯文本升级为可选结构化:
  `{"options":[{"text":"…","love":"flirt"|"kind"|"tease"|"neutral"|"awkward"|"rude"|"reject"}]}`
  后端续写 prompt 要求 2-3 个选项中至少 1 个正向标签;**兼容降级**:AI 输出旧格式纯文本选项时按 text 语义默认 neutral。
- **结算器(LoveEngine)**:玩家点选 → 取标签 → 按 love_rules.affection 模板 ± 值 → state 里该 npc.favor/affection 更新 → 前端好感条动画 + 变化浮字("好感 +4")。**AI 不直接写增减量**,只给标签;模板数值卡级可调。
- **解析端**:parseFull 白名单加 options[].love 字段;storage 层 state-patch 同步支持。

### 4.2 好感 UI 与心动时刻
- 对话界面加**目标角色条**:当前互动对象头像 + 名字 + 好感双条(favor/affection),affection 显示阶段(相识/熟络/心动/倾心 按阈值)。
- **心动时刻卡片**:关键剧情节点(如角色独处/肢体接触/告白前)整幅立绘 + 双语心动句 + 好感变化记录,生成时机由 AI 剧情事件(event 标签)或 affection 越阈触发。
- 列表(5 NPC 横排可切)在播放页侧栏/顶部:显示各角色好感进度,当前锁线标记。

### 4.3 锁线与结局流
- **并行上限**:同时推进 ≥3 条线时,关键节点(由 AI 剧情或系统提示)要求玩家表态;affection ≥ lock_at 自动提示"TA 已经在意你了,再进一步会认真起来"→ 确认后锁线(其他线不增长/选项淡化)。
- **结局判定**:剧情自然收尾或 rounds 上限 → 结算:最高 affection 线 → 达 HE 阈值且触发过心动 → 角色 HE(AI 生成双语告白/结局 epilogue,立绘展示);达 BE 阈值 → 角色 BE;无达线 → 通用遗憾结局。
- 结局文本 AI 生成(接续剧情风格),状态写 save;可重开刷其他线。

### 4.4 词汇:目标等级控词 + 生词动态嵌入
- 等级控词沿用 band:BAND_RULE 按 lang_profile.band 选词域;攻略卡把"对白用词"也纳入(buildInjection 已每轮注入,加对白强调指令)。
- **生词回投(新)**:每轮续写前取生词本(优先未掌握/近期加入/复习到期,上限 ~12 词)拼进 prompt:"以下是你需要复习的单词,请在合理处自然使用:…" → 命中词在 story 高亮/收进当轮产出候选;产出词走现有词卡/划词链路进生词候选。
- 保证不硬塞:指令限定"仅当语境自然,不强用",避免剧情被生词绑架。

### 4.5 卡库与筛选
- lang_cards 查询加 `love_mode / gender_target` 过滤;卡列表恋爱卡显示"恋爱向 · 女/男向"徽标;进入卡前按账号已存向别偏好默认排序(向别偏好存 localStorage,可切)。

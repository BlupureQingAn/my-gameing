## 三、技术侧做了什么

1. **词库**：日语用 openjlpt（JLPT 官方事实标准词表，CC BY-SA）8334 词；韩语用韩国国立国语院 NIKL + TOPIK 官方公开词表，配 HF 的中文释义表。英文/缺释义的走 glm-4-flash 批量转中文（带缓存可断点续跑）。**灌库后做了五类 QC 清洗，详见第四节第 3 条。**
2. **worker 多语种化**：点译提示词拆成 en/ja/ko 三档（**英文那档逐字没动**），日韩要求模型输出**辞书形**且禁止罗马化；有道直译兜底**限英语**（它是英→中链路，日韩句拿过去会错译，宁可留空让前端降级）。
3. **前端**：档位体系按语种分组（英语五档 / 日语 N5-N1 / 韩语初中高），滑块跟着语种换；生成时注入「语种硬锁」；CJK 分词用 `Intl.Segmenter` + 辞书形词干做词库反查（日语的「食べました」能查到「食べる」）。
4. **产线**：去掉写死的 `lang:"en"`，改成按主题语言生成，遇到非英语**直接抛错**——防止产线悄悄产出没有质检口径的日韩卡。

## 四、顺手抓到的两个问题

### 1. 一个真 Bug（已修）

多语种化一上线，**英语剧本库会凭空消失 60 秒**。

根因：语言卡库的内存缓存是**全局单槽**，而它缓存的是「按当前请求语种过滤后的列表」。以前只有英语，没暴露；现在第一个请求如果是 `?lang=ja`（日卡 0 张）→ 缓存写入**空数组**，而空数组在 JS 里是真值 → 60 秒内英语请求命中同一个槽 → **英语剧本库整列表返回空**。

实测复现（探针按 ja→ko→en 顺序请求，en 返回 0 张，正常应为 12 张），改为**按语种分槽**后恢复 12 张。

### 2. 一个安全问题（⚠ 需要你决定）

公开仓库里 `scripts/lang_bank_build.py` **明文存着 PB 超管密码**（和上轮那个发信 token 是同一类问题）。我已经把凭据挪到仓库外的 `F:\Claude\pb-admin.txt`，公开仓库最新代码里已经没有了。

**但密码还在 git 历史里，而且这个密码同时是你服务器的 SSH 密码。** 我没有擅自改（改密码会连带影响一堆脚本和服务器登录），**建议你安排一次轮换**。

### 3. 词库源数据本身是脏的（已清，但仍有余毒）

灌完库我抽样看了一眼，发现**不能直接信源数据**，逐项清洗了五类缺陷：

| 缺陷 | 规模 | 处置 |
|---|---|---|
| 韩语释义是**繁体中文**（HF 数据集源为 zh-TW） | 623 条（維他命…） | opencc 繁转简 |
| **罗马音混入西里尔字母**（源录入污染） | `daieteо`/`Gatollик`/`Yeonguја`/`Peosентeu` | 剔除非 ASCII |
| 日语词形是 openjlpt 的**「异形并记」** | 川/河、いい/よい、见る 観る | 取首形（川/河 → 川） |
| 韩语**词缀碎片**（源表把助词当词收） | `-소` 等 57 条 | 整条丢弃 |
| 释义是**纯英文**（HF 的 `english_term` 本来就是英文，被当成中文写进去了） | 421 条 | 重过 LLM 转中文 |

最终 **14,717 词**（原 14,778，丢弃 61 条畸形/碎片），`check` 对账通过。

**⚠ 但有一类污染我清不掉**：**语义错译**。例如 ビル（多义词）被取成「建筑或账单」、부수다 被译成「安装」、내다 被译成「去」。这是**机器判不出来的**——只能靠母语者或逐条人审。我把它留在 PRD 已标注的「高」风险项里，没敢当作已完成。

清洗脚本已入仓（`scripts/ja_ko_qc.py` / `ja_ko_fix_en.py`），词库可复现。

### ② 韩语档位：三档够吗？

数据只支持「初/中/高」三档（TOPIK 官方口径）。要六档得另找数据。
**建议：先三档。**

### ③ 日语档位：N5-N1 五档？

和英语五档天然对齐，前端滑块结构都不用改。
**建议：就这样。**

### ④ 释义质量：接受「AI 生成 + 抽样人工核」吗？

日语是从英文释义转的，韩语有一部分是模型生成的，**都还没有人工核过**。日语有读音字段、韩语有汉字词字段可以交叉验证。

**我今晚已经跑完机器可检的那部分了**（见四-3：繁转简 / 罗马音 / 词形 / 英文释义，共清掉 5 类缺陷），剩下的**只有语义错译这一类**需要人眼——它是抽样的、稀疏的（我翻了几百条，撞见三五个）。
**建议：先接受上线，语义错译按用户反馈逐条修**；或者你指定一批让我导出成表格，你或找个日韩母语的朋友过一遍。

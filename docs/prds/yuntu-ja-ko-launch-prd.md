## 一、目标

把语言文游从「仅英语」扩展为「英 / 日 / 韩三语可玩」，让用户在语言首页可以把学习语种切到日语或韩语，进入与英语同一套玩法的原生日/韩剧本。

**成功标准**：用户在语言页选「日语」→ 选学习档 → 打开日语卡 → 剧情与选项以日语呈现 → 点句即译出中文。

## 三、两条路径

### 方案 A：复用剧本 · 快速可玩（约 1-2 天）

现有 14 张英语卡的世界设定（`text` 字段）是**英文写成的场景说明书**，对 LLM 而言是"指令"而非"内容"。只要在生成时注入「输出语种 = 日语/韩语」的硬锁，同一张卡就能产出日语剧情。

- **优点**：不用新做剧本，14 张卡立刻三语可玩；与现有玩法 100% 一致
- **缺点**：世界观里写着「当代美国东北部小城大学城」「说话人 Kai，18 岁国际新生」——用日语讲一个美国校园故事，**母语者会觉得别扭**（文化语境错位）
- **适合**：先用最小成本验证"日韩能不能跑通、用户买不买账"

### 方案 B：原生日韩剧本（约 1-2 周）

按现有产线新做日韩本土题材卡（日本：高校/便利店/花火大会/社团；韩国：大学路/考试院/公司会餐/首尔塔），世界设定即为日语/韩语文化语境。

- **优点**：内容真实、母语者不违和，是长期正确的形态
- **缺点**：需要题材设计 + 生成 + QC + 立绘，工作量大；日/韩母语质量**必须要人审**

### 建议

**A 先上、B 跟上**：先用 A 打通全链路并上线可玩版本（用户能玩到日语剧情），同时按 B 节奏补原生剧本，B 的内容成熟一张替换一张。这也和英语当初「先上线再扩卡」的节奏一致。

## 五、词库数据方案（已实测可行）

| 语种 | 来源 | 许可 | 量 | 缺口 |
|---|---|---|---|---|
| 日语 | **openjlpt**（源自 tanos.co.uk，JLPT 事实标准词表） | CC BY-SA 4.0 | N5 662 / N4 632 / N3 1784 / N2 1793 / N1 3463 = **8334 词** | 释义为英文，需转中文 |
| 韩语 | **julienshim/combined_korean_vocabulary_list**（源出韩国国立国语院 NIKL + TOPIK 官方公开词表 2015） | 开源 | **7497 条**（초급 1963 / 중급 4029 / 其他 1505） | **无释义**，只有搭配例句；需 LLM 生成中文释义（可靠汉字字段辅助） |

**中文释义方案**：用 glm-4-flash（免费）批量翻译/生成，分批 + 抽样人工可核。日语 8334 词、韩语约 6000 词，按每批 25 条估算约 600 次调用。

**建议档位划分**：
- 日语：**N5 / N4 / N3 / N2 / N1**（五档，与英语五档天然对齐，前端滑块不用改结构）
- 韩语：**初级(초급) / 中级(중급) / 高级**（三档，数据只支持到这个粒度；若要六档需补数据）

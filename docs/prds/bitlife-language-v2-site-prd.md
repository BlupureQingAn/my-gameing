## 3. 页面规格要点

### 3.1 语言首页(view-lang)
- 头部品牌区:hall-top.jpg(已有)+ 标语 + 语种选择卡(现 ① 原样,EN active/日韩锁)
- **推荐剧本行**:按玩家 band(A/B/C)从英语卡库匹配 3-6 张横向卡;未测档新玩家 → 显示"先测档"引导卡 + 默认推荐(B 档内容?)
- **继续学习行**:该账号该语种有语言存档的卡(hasLangSave)→ 封面+「继续」角标+进度(第 N 轮);无存档 → 整行隐藏
- 顶部保留三枚小入口(测档/沉浸/学习中心),避免功能丢失;下方不再堆 ④⑤ 长列表
- 底部语言导航条(首页/剧本库/学习中心),播放页顶部语言顶栏有"返回语言首页"

### 3.2 剧本库页
- 数据源:**英语原生卡**(见 §5),不再拉官方中文卡列表
- 每卡:封面/标题/题材徽/难度 A/B/C 标签(卡上静态声明)/EN 徽标/「继续」标记(有存档)
- 筛选:题材 chips + 难度 tabs(全部/和我档位匹配 A/B/C);排序:最近玩过/热门
- 点卡:无档 → 轻提示先测档(可跳过直接玩);有档 → 英语开局或续玩(现 M3 逻辑)

### 3.3 学习中心页
- 生词本(现 ⑤ 块整体搬入,头图 vocab-head 保留)
- 我的测档:现 band 结果卡 + 重测按钮 + 手动改档(现 ② 的展示/操作全部搬入;quiz 流程触发时子状态渲染于本页内)
- 学习设置:沉浸模式双卡(现 ③)+ 副文案;预留「辅助开关」空位(M6 打磨可加)
- 原 view-lang 单页里的 ②③④⑤ 各块按上表搬迁,首页只留入口与推荐

## 5. 英语原生卡生态(v2 核心转向)

### 5.1 卡载体与数据结构
- 新 PB 集合 **lang_cards**(管理员写/公开读,与 community_cards 同套路建):
  `title / lang("en") / band(a|b|c 声明难度) / category(题材)/ theme / cover(url 或空→默认)/ data(json:结构化卡,复用编辑器协议 world/event/options/endings + 首轮英语 story)/ status(draft|online)/ play_count / unlock_count / created_at/updated_at`
- 播放:沿用 play 引擎跑结构化卡 + M3 语言引擎(英语生成/语气/难度指令照常)——**语言卡本身是英语,生成续写继续英语**(v0.1 引擎不用改,语言卡天然匹配)
- 编辑/产卡:主站卡编辑器产出的 JSON 可入库(小点人工产卡走脚本/管理员 API 上架,不做新 UI)

### 5.2 首发卡内容工作流(小点执行,独立于本 PRD 编码)
1. 小点研究:高质量英语互动文游/语言学习 IF 卡设计(开篇钩子、选项密度、语言难度曲线、题材适配英语母语场景)
2. 设计规范:首发 3-5 张卡主题建议(如校园留学/都市日常/轻奇幻),每卡长度 8-12 轮可完结,band 标注,首轮即英语剧情
3. 产卡:按编辑器结构化协议写 3 张高质量英语卡(先 1 张端到端试玩验收 → 再 2-3 张)
4. 上架:管理员 API 入 lang_cards → 剧本库可见 → 小徐手机验收内容质量

### 5.3 旧能力下线清单(随 v2 发布)
- 语言剧本库列表源:官方中文卡 → lang_cards(代码:现 LangController 官方卡列表逻辑替换)
- 「同一剧本换种语言玩」「英语进度与中文进度独立」等大厅文案下架(不再有双语同卡)
- 已有英语官方卡存档:保留可玩(老玩家不丢),入口只在「继续学习」短暂保留?→ **默认隐藏**,后续清理(决策待确认)
- M3 起"英语开局中文卡"逻辑保留在引擎层(不再有入口,不删代码,防回滚成本)

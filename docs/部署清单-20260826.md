## 轮次 2026-08-29 · 夸克等浏览器强制暗夜模式封面不可见（commit 62a54f2，仅 index.html）

**背景**：小徐实测——夸克浏览器自带暗夜模式（浏览器级强制暗化，非网站 dark 主题）下，所有卡片封面无法正常显示。

**根因**：页面声明 `color-scheme: light`（:root），Chromium 内核（夸克 U4 基于 Chromium 108+）的 Auto Dark Mode 规则：页面声明 light 且用户开暗夜 → 浏览器对整页做强制反色/压暗。封面浅色渐变（#ffe8c0→#e2b26b）、封面图、白色高光全部被反色 → 内容不可见。且 getComputedStyle 返回原始值，JS 无法检测，仅绘制层改变（Playwright 的 --force-dark-mode / Local State enable-force-dark 在本机 headless 均未触发，无法自动化复现真实反色，靠规范与业界实践确认）。

**改动**（CSS Color Adjustment 规范的拒绝强制改色声明）：
- `:root { color-scheme: only light; }`：声明页面自行适配配色，禁止浏览器强制反色（light 主题）
- `body[data-theme="dark"] { color-scheme: only dark; }`：dark 主题同理（注意：color-scheme 只认根元素，body 上的声明不生效——已由 JS 兜底）
- head 加 `<meta name="color-scheme" content="only light">`（部分 UA 仅读 meta）
- ThemeService.apply 同步 `document.documentElement.style.colorScheme = "only dark" | "only light"`（覆盖 :root 初始值，dark 主题时根元素真正生效 only dark；行内样式优先级最高，不依赖 :has 兼容）

**效果**：夸克暗夜模式下网站保持自身设计的 light/dark 配色，不再被强制反色；网站自己的深色主题（data-theme="dark"）依然可用。

**验证**：Playwright 验证 light 根 color-scheme="light only"、setMode('dark') 后="dark only"、切回="light only"、持久化恢复="dark only"，封面元素（10 卡/shine/emoji）渲染正常零 pageerror；node --check 通过；7 回归探针（batch3/history_swipe/card_color/scroll_fix/name_override/mini_fixes/bigfix_b2）全绿；push→SSH pull；线上抽查 meta/only light/only dark/js 兜底四项全命中。

**待验证（用户侧）**：夸克浏览器开暗夜模式实测封面显示。若夸克为自研滤镜式暗化（非 Chromium Auto Dark），需再评估针对性兜底。
